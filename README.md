# Global Fuel Prices and Taxation Trends

## Project Overview
This project analyzes global fuel prices and taxation trends using Python and CSV datasets.

## Objectives
- Analyze fuel prices across different countries.
- Study differences in fuel taxation.
- Identify trends in global fuel prices.
- Create visualizations to understand the data.

## Tools Used
- Python
- Google Colab
- Pandas
- Tableau
- CSV Dataset

## Project Files
- `tableau.ipynb` — Jupyter notebook containing the project code.
- CSV dataset — Data used for the analysis.

## How to Run
Open the notebook in Google Colab, upload the required CSV dataset, and run the cells in order.
